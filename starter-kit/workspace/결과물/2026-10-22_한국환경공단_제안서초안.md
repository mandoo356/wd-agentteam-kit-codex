# 역할 전환 4단계로 4시간 안에 관리자 실행 기준을 세우는 리더십 교육 제안

## 1. 6개 입력값으로 한국환경공단 교육 조건을 확정합니다

| 항목 | 내용 |
|---|---|
| 고객사 | 한국환경공단 |
| 기관 성격 | 환경부 소관 환경 분야 위탁집행형 준정부기관 |
| 교육 대상 | 행정직 관리자, 인원 확인 필요 |
| 교육 일시 | 2026년 10월 22일 13:00~17:00, 연도 및 일정 확정 여부 확인 필요 |
| 교육 시간 | 4시간, 총 240분 |
| 교육비 | 시간당 500,000원 × 4시간 = 공급가 2,000,000원 |
| 부가세 | 200,000원, 별도 |
| 합계 | 2,200,000원 |

한국환경공단의 정식 기관명과 기관 성격은 ALIO 공시와 공단 공식 자료에서 확인했다. 공단은 환경오염 방지, 환경개선, 자원순환 촉진, 기후위기 대응 정책을 수행한다. 본 제안은 해당 사업을 지원하는 행정직 관리자가 업무 배분과 피드백, 부서 협업의 실행 기준을 세우도록 설계했다.

## 2. 4개 설계 가설로 담당자 문제를 좁힙니다

> 담당자가 풀려는 문제: 확인 필요

아래 내용은 담당자가 말한 사실이 아니다. 행정직 관리자 대상이라는 정보와 한국환경공단의 공식 기능을 바탕으로 세운 설계 가설이다. 발송 전에 담당자가 겪는 실제 사례와 우선순위를 확인해 사례 문구를 바꾼다.

- 관리자가 실무 처리와 팀 조율의 경계를 정해 역할 혼선을 줄이는 문제
- 관리자가 업무 우선순위와 위임 조건을 정해 구성원의 판단 범위를 밝히는 문제
- 관리자가 관찰 사실을 근거로 피드백해 수정 행동을 합의하는 문제
- 관리자가 부서 간 요청과 협의 기준을 정해 업무 인계의 누락을 줄이는 문제

## 3. 4개 산출물로 관리자 실행 행동을 확인합니다

- 관리자가 역할 전환 점검표 1장으로 직접 처리할 일과 팀에 맡길 일을 구분
- 관리자가 위임 대화 4문장으로 목적·권한·점검 시점·완료 기준을 전달
- 관리자가 관찰·영향·요청 3단계로 피드백 문장을 작성하고 동료와 교정
- 관리자가 부서 협업 합의서 1장에 요청 정보·담당·기한·보고 기준을 기록

## 4. 60분 모듈 4개로 240분을 구성합니다

### 모듈 1. 역할 전환 점검표 1장으로 관리자 업무 경계를 정한다

- 학습 목표: 관리자가 실무자 역할과 관리자 역할을 구분하고 이번 주에 바꿀 행동 1개를 선택
- 주요 내용: 관리자 역할 전환, 성과를 만드는 관리 행동, 직접 수행과 위임의 판단 기준
- 학습자 활동: 실제 업무 6개를 직접 수행·위임·공동 수행으로 나누는 역할 지도 작성 25분
- 운영 시간: 13:00~14:00, 60분

### 모듈 2. 위임 대화 4문장으로 업무 배분 기준을 맞춘다

- 학습 목표: 관리자가 목적·권한·점검 시점·완료 기준을 한 번의 대화로 전달
- 주요 내용: 중요도와 긴급도에 따른 우선순위, 위임 수준, 중간 점검, 완료 기준
- 학습자 활동: 행정 업무 사례를 위임 대화 4문장으로 바꾸고 2인 피드백 실시 30분
- 운영 시간: 14:00~15:00, 60분

### 모듈 3. 피드백 3단계로 수정 행동 1개를 합의한다

- 학습 목표: 관리자가 평가 표현을 줄이고 관찰 사실과 다음 행동을 구분해 전달
- 주요 내용: 관찰·영향·요청 구조, 질문과 경청, 방어 반응을 낮추는 대화 순서
- 학습자 활동: 실제 피드백 장면을 3단계 문장으로 작성하고 역할 연습 실시 30분
- 운영 시간: 15:00~16:00, 60분

### 모듈 4. 협업 합의서 1장으로 부서 간 인계 기준을 세운다

- 학습 목표: 관리자가 요청 정보·담당·기한·보고 기준을 명시해 협업 누락을 예방
- 주요 내용: 이해관계자 관점, 업무 요청의 필수 정보, 이견 조정, 보고와 상향 공유 기준
- 학습자 활동: 부서 협업 사례를 합의서에 기록하고 상호 점검해 보완 35분
- 운영 시간: 16:00~17:00, 60분

**시간 합계 검산: 60분 × 4개 모듈 = 총 240분으로 요청한 4시간과 일치함.**

## 5. 4개 시점으로 현업 적용 결과를 확인합니다

| 시점 | 관찰 가능한 결과 | 확인 방법 |
|---|---|---|
| 교육 당일 | 참여자가 역할 전환 점검표, 위임 대화문, 피드백 문장, 협업 합의서를 각 1건 작성 | 산출물 4종 작성 여부 확인 |
| 교육 직후 | 참여자가 현업에서 바꿀 관리 행동 1개와 적용 일정을 기록 | 실행 약속 카드 회수 |
| 교육 후 2주 | 각 참여자가 적용 사례 1건을 제출하도록 운영 | 적용 사례 양식 제출 건수 확인 |
| 교육 후 1개월 | 담당자가 적용 사례를 검토하고 유지·보완 행동을 구분하도록 운영 | 후속 점검 회의 또는 설문 결과 확인 |

2주와 1개월 지표는 교육 운영 권고안이다. 한국환경공단의 내부 보고 체계와 후속 점검 가능 여부를 확인한 뒤 확정한다.

## 6. 실습 120분으로 활동 비중 50%를 확보합니다

| 구분 | 시간 | 비중 | 운영 결과 |
|---|---:|---:|---|
| 개념 설명과 공공기관 행정 사례 | 120분 | 50% | 참여자가 네 가지 관리 도구의 사용 조건을 이해 |
| 개인 작성과 역할 연습 | 120분 | 50% | 참여자가 현업 적용 산출물 4종을 작성 |
| 합계 | 240분 | 100% | 요청한 4시간과 일치 |

인원은 확인되지 않았다. 인원이 확정되면 조 편성, 발표 인원, 피드백 회전 수를 조정한다. 실제 부서 간 협업 사례를 사전에 받으면 익명화해 모듈 4 실습에 반영한다.

## 7. 50만원 × 4시간으로 220만원을 산출합니다

| 산출 항목 | 계산 과정 | 금액 |
|---|---|---:|
| 리더십 교육 진행비 | 500,000원 × 4시간 | 2,000,000원 |
| 공급가 | 교육 진행비 합계 | 2,000,000원 |
| 부가세 | 공급가 2,000,000원 × 10% | 200,000원 |
| 최종 합계 | 공급가 2,000,000원 + 부가세 200,000원 | 2,200,000원 |

- 부가세는 별도
- 교통비·숙박비·교재 인쇄비 포함 여부는 확인 필요
- 교육 장소와 결제 조건은 확인 필요
- 견적 유효기간은 확인 필요

## 8. 3개 전문 축으로 4개 모듈을 연결합니다

김민주는 위드드림컨설팅 대표이며 리더십·조직, 소통, 문제해결 교육을 진행한다. 아래 정보는 옵시디언의 강사 마스터 프로필을 기준으로 작성했다. 발송 전 최신 상태와 증빙을 확인한다.

| 구분 | 내용 |
|---|---|
| 현직 | 위드드림컨설팅 대표 |
| 학력 | 한양대학교 조직심리학과 석사과정, 최신 상태 확인 필요 |
| 자격 | HRD-net NCS 인증강사, 퍼실리테이터 2급, 전문코치 2급, MBTI 일반강사 |
| 강의 영역 | 신임 리더·현장관리자 리더십, 셀프리더십, 팔로워십, 갈등관리, 성격진단 기반 소통 |

## 9. 8개 확인 항목으로 발송 전 조건을 닫습니다

- 교육 인원
- 교육 일자의 연도와 일정 확정 여부: 본 제안은 2026년 10월 22일로 가정
- 담당자가 실제로 풀려는 문제와 현업 사례
- 교육 장소
- 교통비·숙박비·교재 인쇄비 포함 여부
- 결제 조건과 견적 유효기간
- 강사 학력·자격의 최신 상태와 증빙
- 2주·1개월 후속 점검 운영 여부
