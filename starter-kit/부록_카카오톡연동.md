# 부록 — 카카오톡 알림 연동 (수업 시간 밖, 혼자 하는 것)

> 📌 **왜 본편에서 뺐나** — 카카오 인가코드는 **받은 뒤 10분 안에** 써야 만료됩니다.
> 30명이 강의장에서 동시에 이 10분짜리 구간을 통과해야 하면 실패율이 가장 높은
> 구간이 됩니다. 그래서 이건 **집에서, 혼자, 시간 여유 있을 때** 하는 것으로 뺐습니다.
> 본편(문의 접수 웹앱)은 이것 없이도 완전히 동작합니다 — 메일 알림만으로 충분합니다.

**하는 일**: 웹앱에 문의가 접수되면 카카오톡으로 나에게 알림이 오게 만듭니다.
"카카오톡 채널"로 고객에게 보내는 게 아니라, **내(대표) 카카오톡으로 나에게 보내는** 방식이라
비즈니스 심사 없이 바로 씁니다.

---

## 1단계 — 카카오 개발자 앱 만들기

1. [Kakao Developers](https://developers.kakao.com) 에 카카오 계정으로 로그인
2. **내 애플리케이션 → 애플리케이션 추가하기** → 앱 이름(예: 내회사문의알림) 입력
3. 앱 생성 후 **앱 설정 → 요약 정보**에서 **REST API 키**를 복사해 메모장에 붙여둡니다.
   (네이티브 앱 키·JavaScript 키와 헷갈리지 마세요. 쓰는 건 **REST API 키**입니다.)

## 2단계 — Redirect URI 등록 (Apps Script 쪽 스크립트ID가 필요합니다)

카카오 로그인은 인가코드를 "어디로 돌려보낼지" 주소가 있어야 합니다. 문의 웹앱을 만들 때
쓴 Apps Script 프로젝트의 **스크립트 ID**를 그 주소로 씁니다.

1. Apps Script 편집기 → 왼쪽 톱니 **프로젝트 설정** → **스크립트 ID** 복사
2. 아래 형식으로 Redirect URI를 만듭니다.
   ```
   https://script.google.com/macros/d/여기에_스크립트ID_붙여넣기/usercallback
   ```
3. Kakao Developers → **제품 설정 → 카카오 로그인 → 활성화 설정 ON**
4. 같은 화면의 **Redirect URI**에 2번에서 만든 주소를 등록

## 3단계 — 동의 항목 설정

**제품 설정 → 카카오 로그인 → 동의항목** 에서 **카카오톡 메시지 전송(talk_message)** 을
"필수 동의"로 설정합니다. (나에게 보내기 용도라 별도 비즈니스 심사가 필요 없습니다.)

## 4단계 — 클라이언트 시크릿 비활성화

**제품 설정 → 카카오 로그인 → 보안** 에서 **Client Secret 사용 안 함**으로 둡니다.
(이 부록에서 쓰는 방식은 시크릿 없이 REST API 키 + 인가코드만으로 토큰을 받는 가장 단순한
흐름입니다. 시크릿을 켜두면 아래 6단계 요청이 거부됩니다.)

---

## 5단계 — 인가코드 받기 (⏱ 여기서부터 10분)

브라우저 주소창에 아래 URL을 붙여넣습니다. `client_id`와 `redirect_uri`를 본인 값으로 바꾸세요.

```
https://kauth.kakao.com/oauth/authorize?client_id=여기에_REST_API_키&redirect_uri=여기에_Redirect_URI&response_type=code&scope=talk_message
```

카카오 로그인 → **동의하고 계속하기**를 누르면 주소창이 `.../usercallback?code=` 로 바뀝니다.
**`code=` 뒤의 값을 그대로 복사하세요.** 이게 인가코드이고, **10분이 지나면 무효**가 됩니다.
바로 다음 단계로 넘어가세요.

## 6단계 — 액세스 토큰 받기

Apps Script 편집기에서 **파일 → 새로 만들기 → 스크립트 파일** 이름을 `카카오토큰`으로 만들고
아래를 붙여넣은 뒤, `함수 실행 ▶`으로 **바로** 실행합니다(인가코드가 만료되기 전에).

```
너는 비개발자를 도와주는 Google Apps Script 자동화 선생님이야.

카카오 인가코드를 액세스 토큰으로 교환하는 함수를 만들어줘.

[내 값]
- REST API 키: [여기에 REST API 키]
- Redirect URI: [여기에 Redirect URI]
- 인가코드: [여기에 방금 받은 code 값]

[요구사항]
- 함수 이름은 getKakaoToken()
- UrlFetchApp.fetch 로 https://kauth.kakao.com/oauth/token 에 POST 요청
- grant_type=authorization_code 로 요청하고, 받은 access_token과 refresh_token을
  Logger.log 로 화면에 찍어줘
- access_token은 스크립트 속성(PropertiesService)에 KAKAO_ACCESS_TOKEN 이름으로
  저장하는 코드도 같이 만들어줘
- 오류가 나면 응답 본문을 그대로 로그에 찍어서 원인을 알 수 있게 해줘
```

실행 후 **보기 → 로그**에서 `access_token` 값이 찍히면 성공입니다. 저장까지 됐는지
**프로젝트 설정 → 스크립트 속성**에서 `KAKAO_ACCESS_TOKEN` 항목이 보이는지 확인하세요.

> ⚠️ **access_token은 6시간 뒤 만료됩니다.** 오늘 테스트용이면 충분하지만, 계속 쓰려면
> refresh_token으로 갱신하는 별도 트리거가 필요합니다 — 이건 상시 자동화라 본편에서
> 뺀 것과 같은 이유로 오늘 범위 밖입니다. 필요해지면 그때 새로 요청하세요.

## 7단계 — "나에게 보내기" 테스트

```
카카오톡 "나에게 보내기" API로 테스트 메시지를 보내는 함수를 만들어줘.

- 함수 이름은 sendKakaoTestMessage()
- 스크립트 속성에 저장된 KAKAO_ACCESS_TOKEN 을 읽어서 사용
- https://kapi.kakao.com/v2/api/talk/memo/default/send 로 POST
- 메시지 내용: "카카오톡 알림 연동 테스트입니다"
- object_type은 text로
- 실패하면 응답 내용을 로그에 그대로 찍어줘
```

`함수 실행 ▶` 후 본인 카카오톡에 메시지가 오면 성공입니다.

## 8단계 — 문의 웹앱에 연결하기

여기까지 성공했으면, 본편에서 만든 문의 웹앱의 `Code.gs`를 열고 이렇게 요청하세요.

```
방금 만든 sendKakaoTestMessage() 의 전송 부분을 참고해서, submitForm(data) 안에
sendKakaoAlert_(data) 를 추가해줘.

- 새 문의가 접수될 때마다 "[새 문의] {{신청자 성함}} / {{교육 주제 및 목적}}" 내용으로
  나에게 보내기로 카카오톡 알림을 보낸다
- 카카오 전송이 실패해도 시트 저장·메일 발송은 그대로 진행되도록 try-catch 로 감싼다
  (카카오가 죽어도 문의 자체는 놓치지 않아야 한다)
- KAKAO_ACCESS_TOKEN 이 스크립트 속성에 없으면 카카오 전송만 건너뛰고 조용히 넘어간다
```

**통과 기준** — 웹앱에서 테스트 문의를 접수했을 때 메일과 카카오톡 알림이 **둘 다** 옵니다.
카카오만 안 오면 6단계(토큰 만료 여부)부터 다시 확인하세요.

---

## 자주 걸리는 것

| 증상 | 원인 |
|---|---|
| `code=` 를 못 받고 오류 화면이 뜬다 | Redirect URI가 카카오 콘솔에 등록한 것과 **한 글자도 안 틀리고** 같아야 합니다 (마지막 `/` 포함) |
| 토큰 교환 요청이 거부된다 | 4단계(Client Secret 사용 안 함)를 안 했을 가능성. 또는 인가코드가 10분 지나 만료 — 5단계부터 다시 |
| "이 앱은 카카오 로그인 검수가 필요합니다" | talk_message 를 필수 동의로 안 걸었거나, 다른 사람 계정으로 테스트 중입니다 — 앱 만든 본인 계정으로만 우선 테스트하세요 |
| 6시간 지나니 안 온다 | access_token 만료입니다. 5~6단계를 다시 하거나, 필요하면 refresh_token 갱신을 별도로 요청하세요 |
