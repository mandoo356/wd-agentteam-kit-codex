시작 메뉴에서 Windows PowerShell을 열고 위 명령을 붙여넣은 뒤 Enter를 누르세요. 붙여넣기는 마우스 오른쪽 클릭입니다. 관리자 권한은 필요 없습니다.

자동으로 하는 일

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/mandoo356/wd-agentteam-kit-codex/main/install.ps1 | iex"

PowerShell의 irm은 CMD에서 직접 실행되지 않습니다. 위 명령은 PowerShell을 호출합니다. 프로그램 자체가 차단된 PC는 별책 검은 창 매뉴얼 5장을 참고하세요. 훅 실습은 PowerShell 사용 가능한 PC에서 진행합니다.

[작성 원칙]

- 기대효과는 형용사가 아니라 담당자가 윗선에 보고할 수 있는 문장으로.
  ✕ "역량이 향상됩니다"
  ○ "교육 후 2주 내 각 팀이 적용 사례 1건씩을 제출합니다"
- 견적은 단가 × 시간 계산 과정을 표에 보이고, 부가세 별도 여부를 반드시 쓴다.

[절대 금지]

[문장 규칙 — 여기 적히는 모든 글에 적용]

- 한 문장에 한 메시지만 담는다. 두 문장을 넘기지 않는다.

  ○ "- 담당자 사전 협의 1회로 업종 사례를 맞춰 당일 이해도 편차 축소"

[이 스킬이 하는 일]
학습자가 손에 쥐고 쓰는 워크북을 만든다. 진행 설계가 아니라 배포물이다.
결과물을 두 개 만든다 — 내용(.md)과 인쇄용 워크북(.html).

[Step 0 — 착수 전 확인할 것]
  1. 무엇을 근거로 만드나 — 확정된 교안 또는 제안서 (파일 경로)
  2. 어떤 형식 — 학습자용 워크북 / 강사용 교재 (기본: 학습자용 워크북)
  3. 인쇄 부수와 흑백/컬러
  4. 제출 마감일

  → 1번이 없으면 만들지 않는다. 근거 없이 만든 교재는 강의와 따로 논다.
     교안도 제안서도 없으면 "제안서부터 만드시겠어요?" 하고 되묻는다.
  → 4번은 받는 즉시 알려준다. 교재 마감은 강의일보다 먼저 온다.

[챕터마다 반드시 들어갈 여섯 블록]

  본문           — 설명. 예시는 학습자 업종에서 가져온다
  실습 / 워크시트 — 직접 써보는 칸
  ✓ CHECK       — 스스로 확인하는 질문 2~3개
  핵심 요약      — 3줄 이내

[작성 원칙]
- 워크북은 빈칸만 있으면 손이 안 간다. 맨 위 한 줄에 예시를 채워두고 나머지를 비운다.
- 실습지는 한 쪽에 하나만.
- 챕터는 교안(또는 제안서)의 모듈과 1:1로 맞춘다. 모듈이 4개면 챕터도 4개다.
- 흑백 인쇄를 전제로 색으로만 구분되는 표시를 쓰지 않는다.

[절대 금지]
- 근거 문서에 없는 내용을 교재에 넣지 않는다. 필요하면 근거부터 고친다.
- 출처 없는 통계·인용을 싣지 않는다.
- 강의 진행 방법(시간표·활동 운영)을 교재에 넣지 않는다. 그건 교안이다.

[문장 규칙 — 여기 적히는 모든 글에 적용]
- 제목은 [핵심 수단] + [정량 수치] 로 쓴다. 추상적 제목을 쓰지 않는다.

- 서술형 문장은 마침표를 찍는다.

2단계 — 열쇠 두 개와 내 멤버 ID 받기

받을 것은 세 값입니다. 열쇠 두 개는 서로 다른 페이지에 있어서 한 화면에서 둘 다 받을 수 없고, 멤버 ID는 슬랙 앱에서 받습니다. 하나만 받고 끝난 줄 아는 경우가 가장 많습니다.

첫 번째 열쇠 xapp- — 왼쪽 메뉴 Basic Information

이 페이지는 세로로 아주 깁니다. App Credentials 라는 칸 바로 다음에 App-Level Tokens 가 있습니다. 못 찾으시면 Ctrl+F → App-Level.

  1. Generate Token and Scopes 클릭
  2. 이름 칸에 아무거나 — socket 이라고 치시면 됩니다
  3. 그 아래 Add Scope → connections:write 선택 ← 이걸 빼먹으면 나중에 서버가 안 켜집니다
  4. Generate → 나오는 긴 글자를 그 자리에서 Copy → 메모장에 붙여넣기
🚨 창을 닫기 전에

이 창을 닫으면 이 글자는 다시 볼 수 없습니다. 슬랙이 보관은 하지만 화면에 보여주지 않습니다.

이미 닫으셨다면 괜찮습니다 — 새로 하나 더 만들면 됩니다. 여러 개 만들어도 문제없습니다. 다만 이번엔 connections:write 를 잊지 마세요.

두 번째 열쇠 xoxb- — 왼쪽 메뉴 OAuth & Permissions

  1. 페이지 맨 위 Install to Workspace 클릭 → 허용
  2. 설치가 끝나면 그 자리에 Bot User OAuth Token 이 새로 생깁니다
  3. Copy → 메모장에 붙여넣기
이건 안심하셔도 됩니다
