# 내 AI 회사 — Codex 공통 규칙

- 모든 답변과 파일은 한국어로 작성한다.
- 작업 전 `workspace/memory/facts.md`를 읽는다.
- 직원별 정체성과 역할은 `.codex/agents/*.toml`을 따른다.
- 반복 업무는 `.agents/skills/*/SKILL.md`의 스킬을 사용한다.
- 산출물은 `workspace/결과물/`에 저장하고 마지막 답에 전체 경로를 쓴다.
- 다른 직원에게 넘길 일은 `workspace/inbox/<상대>/`에 쪽지로 남긴다.
- 사용자가 주지 않은 금액·날짜·고객사 이름은 지어내지 않는다.
- 슬랙에서는 한 줄에 한 사람씩, 전체 5줄 이내로 답한다.
- 여러 직원이 독립적으로 처리할 수 있는 일은 해당 직원을 하위 에이전트로 호출하고 결과를 모은다.


## 작업 보존·위험 작업 (2026-09-05)
- 삭제·이동·기존 문서 전체 덮어쓰기·팀 규약 변경 전에는 대상과 변경 내용을 알리고 사용자의 명시적 지시를 확인한다.
- 훅이 차단한 작업은 다른 도구로 우회하지 않는다. 백업과 변경 대상을 설명하고 사용자가 노트북 터미널에서 직접 실행하도록 안내한다.
- 슬랙에서 위험 작업을 대신 실행하지 않는다. 일반 문서의 필요한 수정은 apply_patch로 하고 새 직원·스킬 파일 생성은 허용한다.
- 점검.py·.codex/hooks.json·.codex/hooks/·configure_hooks.ps1은 강사가 관리한다.
- MyData의 원본은 읽기만 한다. 결과는 workspace/결과물/에 새 파일로 저장한다.
- /hooks에서 신뢰한 경우 작업 기록과 Git 자동 저장을 사용한다. 기록 실패는 숨기지 말고 보고한다.
