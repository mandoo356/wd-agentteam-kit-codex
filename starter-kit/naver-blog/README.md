# 네이버 블로그 임시저장 자동화

블로그 초안(`.md`)을 **네이버 블로그 임시저장함**에 자동으로 넣는 도구입니다.
Codex in Chrome 확장은 `blog.naver.com` 을 허용하지 않아서, 전용 Chrome
프로필을 Playwright로 직접 띄우는 방식으로 만들어졌습니다.

**발행(공개)은 하지 않습니다.** 임시저장까지만 자동입니다.

## 1. 사전 조건

| 필요한 것 | 확인 방법 | 없으면 |
|---|---|---|
| Python 3.10 이상 | `py -3 --version` | 스타터킷 설치 안내(PART 1) 참고 |
| playwright 패키지 | `py -3 -c "import playwright"` | `pip install playwright` |
| 시스템 Chrome | Chrome이 설치돼 있는가 | google.com/chrome |
| 본인 네이버 블로그 | blog.naver.com 계정 | 없으면 이 단계는 건너뛰어도 됩니다 |

## 2. 최초 1회 — 본인 네이버 계정 로그인

**비밀번호는 이 도구가 절대 입력하지 않습니다.** 창이 뜨면 직접 로그인하세요.

```
py -3 naver_draft.py login --blog-id 내블로그아이디
```

`내블로그아이디`는 본인 블로그 주소(`blog.naver.com/이아이디`)의 그 부분입니다.
로그인이 확인되면 세션이 `.naver-state.json` 에 저장됩니다.

🔒 **`.naver-state.json` 은 로그인 토큰입니다.** 이 파일이 유출되면 로그인 없이도
계정에 접근할 수 있습니다. 절대 남에게 보내거나 클라우드에 올리지 마세요.
(`.gitignore` 에 이미 제외돼 있습니다.)

세션이 살아있는지 확인:

```
py -3 naver_draft.py check --blog-id 내블로그아이디
```

## 3. 임시저장

```
py -3 naver_draft.py draft --blog-id 내블로그아이디 --title "제목" --body-file 원고.md
```

이미지를 직접 지정하려면:

```
py -3 naver_draft.py draft --blog-id 내블로그아이디 --title "제목" --body-file 원고.md \
  --images "img1.png,img2.png"
```

아무 이미지도 안 주면 **기본 3장을 직접 생성**합니다(아래 4번). 글만 올리려면
`--no-images` 를 붙이세요.

## 4. 이미지 — 두 가지 방법 중 고르세요

| | Gemini 자동생성 (`gen_image.py`) | Google Flow 배치생성 (`flow-image-JJ` 스킬) |
|---|---|---|
| 비용 | 유료 API (장당 몇 센트) | 계정만 있으면 무료(일일 한도 있음) |
| 방식 | 완전 자동 — `draft` 실행 시 알아서 생성·삽입 | Codex에게 "구글 플로우로 이미지 만들어줘"라고 시켜서 파일로 받은 뒤 `--images` 로 넘김 |
| 준비물 | `.env` 에 `GOOGLE_API_KEY` (결제 등록된 구글 클라우드 프로젝트) | `flow-image-JJ` 스킬 설치 + 본인 구글 계정 최초 로그인 |

**Gemini로 자동생성**하려면 이 폴더에 `.env` 파일을 만들고 한 줄만 적으세요.

```
GOOGLE_API_KEY=여기에_키
```

## 안전 규칙 (스크립트에 이미 들어 있음)

1. **"발행" 버튼을 누르지 않는다.** 임시저장("저장")까지만.
2. **비밀번호를 입력하지 않는다.** 로그인은 항상 사람이 직접.
3. **복구 팝업에서 "확인"을 누르지 않는다.** 기존 임시저장을 덮어쓰지 않도록 항상 "취소".
4. **임시저장 목록에서 제목을 확인하기 전에는 "저장했다"고 보고하지 않는다.**

## 문제 해결

| 증상 | 원인 / 대응 |
|---|---|
| `로그인 필요` | 세션 만료. `login` 재실행 |
| 저장 버튼을 못 찾음 | 네이버 에디터 구조가 바뀜. `probe` 모드로 진단 |
| 이미지 삽입 실패 | `--auto-images 0 --no-images` 로 글만 먼저 저장해보고 원인 분리 |
| 종료 코드 `2` | 로그인 필요 |
| 종료 코드 `3` | 저장은 시도했지만 목록에서 확인 못 함 — 네이버에서 직접 확인 |
| 종료 코드 `4` | 제목·본문 입력 실패 |
